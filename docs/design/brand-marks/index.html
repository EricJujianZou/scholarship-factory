UGMI — mark & favicon gallery

One mark that works as both the site logo and the 16px favicon. Every concept is shown at logo size, at 32px and at a true 16px, then dropped into a light and a dark browser tab — the two places a favicon actually lives. Checkered stage = transparent background, so you can see which marks vanish on a dark tab.

All concepts speak the existing site language: ink, the yellow highlighter wash, bold-800 type, the mono scraper voice. Ordered safe → wild.

Recommendation

Ship #03 (yellow-tile) as the favicon and #02 (u-marked) as the logo. They are the same U geometry in two dressings, so they read as one identity: the tile survives 16px and dark tabs because it carries its own background, and the swiped U is literally the site's .mark highlighter move promoted to a logo — nothing new is invented.

  • Runner-up, more ownable: #14 (swipe) — the only abstract mark here; distinctive in a tab strip full of letters, but it gives up the "U".
  • Runner-up, more voice: #09 (u-cursor) — the scraper's mono voice; strongest with the r/csMajors crowd, weakest with everyone else.
  • Avoid: #04 and #13 at favicon size (text mush / reads as a notification badge); #17 breaks the two-hue palette for the leaf.
