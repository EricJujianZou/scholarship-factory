# Component: Hook bank + scent rule

## Intent
Stages 1→3. The Reels bridge: frame-one hook grammar plus the unbroken scent
trail (information foraging — a promise mismatch is diagnostic of grift, not
just confusing). This component is half content-machine's: mirror the rule
there.

## The hard rule (the constitution)
**No hook ships unless its key phrase appears in (a) the DM template for
that reel and (b) the first viewport it links to.** Enforced at hook-writing
time, not page-design time. The Stripe click inherits whatever trust the
trail accumulated.

## Anatomy — the hook bank
Formulas keyed to proven mechanics, always with a real number computed from
the actual DB (never a placeholder):
- **Specific-number outcome** (the proven 68k genre): "1,427 internships are
  on this site. You're eligible for maybe 60."
- **Contact-finding** (the outlier genre): "The recruiter's name is in this
  reel." → must land where "the actual person to contact" is visible in the
  first screen.
- **Labor receipt:** "I read 400 postings this week so you don't."
- **Closings stat:** "23 internships closed this week — here's what's still
  open."
- **Subtractive frame** (CS-audience native): "LeetCode has 3,000 problems;
  everyone does the NeetCode 150. There are 1,427 internships live; here's
  your 10."
- **Collapse demo:** screen-record the 3-tap eligibility collapse: "watch
  1,427 become 43."
Grammar constraints (from the feed teardown): on-screen text from frame one,
5–8 words, legible on mute; mid-action start, no greeting intros.

## Landing-side mechanics (static-compatible)
- Recurring genres get fragment links that pre-scroll/pre-filter the DB.
- Optional: one-line H1 variant reading a `?from=` param client-side.
- The human DM is the adapter whenever the site can't restate the promise —
  a manual sender can restate it in the viewer's own context.

## States
- **Hook → page match:** the phrase from the reel is findable in viewport
  one. That's the test — run it before publishing, literally.
- **Day 40:** the bank grows only from hooks whose reels performed AND whose
  landing kept the promise; retire hooks the page can no longer cash.

## Copy tone
Claims scoped the Wealthsimple way: never "the best internship list" —
"214 Canadian internships this week; the big GitHub lists carry ~30."
Scoped, dated, checkable.

## Anti-pattern (named, never ship)
**The bait-cash gap**: a hook the landing page can't repeat verbatim
("guaranteed interviews", inflated counts, curiosity-gap bait). With this
audience an overclaimed hook converts views into distrust — the most
expensive possible impression.

## Marketing reuse
This component IS marketing — mirror it into content-machine's queue
workflow as a pre-publish checklist item ("scent check: phrase in DM
template? phrase in first viewport?").
