# Component: DM playbook

## Intent
Stage 2 (with a stage-4 note). The DM is the first trust checkpoint and the
actual sales surface. Mechanism: keep the comment tollgate, weaponize the
manual-ness — a visibly-human reply is a pattern interrupt against the
ManyChat vending machine every student has already received.

## Anatomy
1. **The tollgate reply (public):** respond to the "LINK" comment with
   "sent!" — the public trail is the social proof.
2. **The delivery DM (the pattern interrupt):** first message delivers the
   link unconditionally — no follow-gate, no email ask, no emoji confetti.
   One clause references *their* context: "here you go — the DB is free,
   filter by your term. you commented on the PitchBook reel — same method
   works for these."
3. **Scent continuity:** the DM restates the reel's exact promise phrase
   (see hook-scent-rule.md) before the link.
4. **The pitch (later, not in the toll):** only after the free thing landed.
   Price reveal uses the calm-checkout fee grid verbatim.
5. **The /start ritual (on purchase):** three questions BEFORE the first
   list — "program? grad year? location constraints?" — echoed back in
   delivery week 1: "Your filter: CS, class of 2028, GTA or remote." The
   customer co-builds the product; week-2 retention lives here.
6. **Cadence mechanics:** batch DM sessions twice a day (bounded latency);
   scale valve: if a reel outruns capacity, pin a comment with the raw link
   — losing that cohort's DM entry is cheaper than a public backlog of
   unanswered "LINK" comments.
7. **Mid-week ping (stage 4):** IG broadcast channel as our #intern-alerts
   — 2-3 "just added" listings mid-week; members are the warm pool for the
   paid pitch.

## States
- **High-intent commenter** (asked a question, not just "LINK"): answer the
  question first, link second.
- **Second-hand arrival** (DMs without seeing a reel): no scent to continue
  — open with the pulse-strip facts instead ("1,412 live right now, free,
  no email").
- **Post-purchase:** thread becomes the delivery channel; continuity notes
  per subscriber (the operator is the system of record).
- **Day 40:** same voice at message 40 as message 1 — scripts may exist,
  pasted blocks may not read as pasted.

## Copy tone
Signed like a text. Lowercase acceptable — it's the owner's actual register.
Never: auto-DM cadence ("Hey there! 🎉 Thanks so much for reaching out!"),
follow-gating ("follow me first and I'll send it"), or a pitch in the first
message.

## Anti-pattern (named, never ship)
**The vending machine**: any DM a student could mistake for ManyChat.
Automation is not forbidden forever — but it forfeits the differentiator;
revisit only when volume forces it, and never for the first message.

## Marketing reuse
This IS the marketing surface. The /start echo doubles as content: "every
subscriber starts with 3 lines" is a reel about how the product works.
